# Dataset notice

NOAA/NCEI U.S. Historical Climatology Network observations, using the sporadic subset distributed by GRU-ODE-Bayes (De Brouwer, Simm, Arany, Moreau, NeurIPS 2019). This release preserves the supplied benchmark transformation and changes its storage format.

Source subset: https://github.com/edebrouwer/gru_ode_bayes/tree/master/gru_ode_bayes/datasets/Climate
NOAA data policy: https://www.ncei.noaa.gov/sites/default/files/2023-12/NCEI%20PD-10-2-02%20-%20Open%20Data%20Policy%20Signed.pdf
